Git

  • git init - расшифровывается как "Git initialize", что переводится как "Инициализация Git" Создает новый пустой Git-репозиторий в текущей папке.
  • git clone - переводится как "клон", "клонировать". Создает точную копию удаленного проекта на локальный компьютер.
  • git push - переводится как "толкнуть", "нажимать". Означает отправку или выгрузку локальных коммитов и изменений на удаленный сервер.
  • git pull - переводится как "тянуть" или "тащить". Это команда для получения изменений из удаленного репозитория на локальный компьютер .
  • git commit -переводится как "фиксировать", "совершать". Команда для сохранения изменений в удаленном репозитории. /
